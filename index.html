FREQUENTLY ASKED

Frequently Asked Questions

Everything you need to know about Code Snippets Pro, Safe Mode, and Cloud Sync.

What happens if a custom code snippet contains a PHP syntax error?
Code Snippets Pro contains a built-in Safe Mode and automated error-trapping engine. If any snippet causes a fatal PHP error during execution, Code Snippets automatically catches the exception, deactivates that specific snippet immediately, and displays a detailed admin notice with stack trace information instead of bringing down your website with a White Screen of Death (WSOD).
Can Code Snippets completely replace my theme's functions.php file?
Yes! Directly editing a theme's functions.php file is dangerous because theme updates wipe out custom changes unless you maintain complex child themes. Code Snippets stores custom functions independently in the WordPress database, ensuring your customizations remain permanently active regardless of theme updates or theme switches.
How does Multi-Site Cloud Synchronization work across client websites?
With Cloud Sync in Code Snippets Pro, you can connect your central encrypted snippet repository to all your WordPress client sites. When you create or update a snippet in the cloud dashboard, updates deploy automatically across your entire network in real-time.
Is Code Snippets compatible with WooCommerce, Elementor, and Gutenberg?
Yes, 100%. Code Snippets runs on native WordPress hooks, actions, and filters. It is fully compatible with WooCommerce, Elementor, Divi, Bricks, Gutenberg Block Editor, ACF, and all major plugins.
How does the WordPress-trained AI Assistant work?
Code Snippets AI uses machine learning models fine-tuned on the WordPress Core API and developer handbook. You can request custom post types, rewrite filters, add WooCommerce price discounts, or optimize database queries in plain English directly inside your dashboard.
