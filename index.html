Got Questions?

Frequently Asked Questions

Everything you need to know about Code Snippets Pro.

What happens if a code snippet contains a syntax error?
Code Snippets includes built-in Safe Mode and real-time syntax checking. If a snippet triggers a fatal PHP error during execution, Code Snippets automatically catches the exception, deactivates the faulty snippet, and displays a friendly warning notice in your dashboard instead of bringing down your site.
Can Code Snippets replace my theme's functions.php file completely?
Yes! Adding code to your theme's functions.php file is dangerous because theme updates overwrite your changes. Code Snippets stores custom functions independently in your database, ensuring your code remains active even when switching themes or updating plugins.
How does Cloud Synchronization work across multiple sites?
With Cloud Sync in Code Snippets Pro, you can connect your central library to all your WordPress client sites. When you create or update a snippet in the cloud, changes deploy automatically across your connected network.
Is Code Snippets compatible with WooCommerce, Elementor, and Divi?
Absolutely. Code Snippets runs standard WordPress hooks, actions, and filters, making it 100% compatible with WooCommerce, popular page builders, membership plugins, and custom themes.
How does Code Snippets AI work?
Code Snippets AI integrates deep learning models trained specifically on WordPress APIs. You can ask it to generate code snippets, explain existing code, or optimize performance directly inside your code editor.
